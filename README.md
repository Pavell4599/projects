Классы и сущности
✅ Player
    Создаётся с цветом замка (player_color) и именем.
    Пример: Player('red', 'Pasha_victory_man')
🏰 Castle
    Ваша база. Хранит монстров и героя.
    Методы:
        create_monster(mon_name, mon_count) — создаёт указанное количество монстров в замке.
        mons_in_castle_list — словарь с монстрами в замке.
        mons_with_hero_list — словарь с монстрами, идущими с героем.
🤺 Hero
    Герой, управляемый игроком.
    Имеет здоровье (hp = 1500), может выходить из замка, проверять состояние монстров и сражаться.
    Главные методы:
        go_outside() — выходит из замка.
        go_inside(group='') — возвращается в замок. Если group='all', все монстры уходят в замок.
        check_hero_hp() — показывает здоровье героя.
        check_monster_hp(mon_name) — показывает здоровье конкретного типа монстров (в замке и с героем).
        check_all_hp() — выводит всё: здоровье героя, всех монстров в замке и с ним.
        take_monsters_from_castle(group='', **mon_list) — берёт монстров из замка к герою.
        group='' — берёт указанные монстры по индексу.
        group='all' — берёт всех монстров из замка (если не превышает лимит).
        group='random_3' — берёт 3 рандомных монстра.
        group='5' — берёт первых 5 монстров.
        send_monsters_to_castle(group='', **mon_list) — отправляет монстров обратно в замок.
        group='all' — отправляет всех монстров.
        atack(enemy_name, order='') — начинает битву с вражеским НПС.
        order='random' — монстры выходят в случайном порядке.
        randomize(target) — пока не реализован.
🧑‍🌾 NPC
    Вражеские персонажи на карте (Фермер, Боярин и т.д.).
    Каждый NPC имеет армию из 1–3 монстров каждого типа.
    Метод npc_list_check() — выводит список монстров у NPC.
🗺️ Map
    Карта, где расположены вражеские НПС.
    Создаёт рандомное количество NPC (6–12) и нумерует их.
🐉 Монстры
    General, Skeleton, Pig, Helicopter, Foodman — классы монстров.
    У каждого есть имя, здоровье (hp) и урон (dmc).




------------Возможный сценарий игры------------
player_1 = Player('red', 'Pasha_victory_man')
castle_1 = Castle(player_1)

# Создаем монстров в замке
castle_1.create_monster('Skeleton', 3)
castle_1.create_monster('General', 1)

map_1 = Map('Forest_of_Doom')
hero_1 = Hero(castle_1, map_1)

# Проверяем состояние
hero_1.check_all_hp()

# Берем 2 рандомных монстра
hero_1.take_monsters_from_castle(group='random_2')

# Выходим на карту
hero_1.go_outside()

# Смотрим, кто на карте
hero_1.check_map()

# Атакуем первого Фермера
hero_1.atack('Фермер_0', order='random')

# После битвы возвращаемся в замок со всеми монстрами
hero_1.go_inside(group='all')
